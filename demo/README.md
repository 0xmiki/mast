# Mast — browser demo

Interactive SvelteKit mock of **Mast**, a productivity browser where commitments ("pacts")
are irreversible and built into the browser rather than an extension.

```sh
bun install
bun run dev
```

Open the **Demo** drawer (bottom-left) to load example pacts, time-travel, and try to escape.
Product rules, pact types, and the Chromium mapping live in [docs/SPEC.md](docs/SPEC.md).
