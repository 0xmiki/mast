# Working on Mast

Mast is a deep-work browser built on ungoogled-chromium. Linux only for now.

## Where things are

- `browser/`: the browser. `./mast` (run from `browser/`) is the CLI for everything: building
  on a rented Hetzner server, screenshots, releases. Mast's own code is `browser/src/mast`;
  its edits to Chromium are generated by `browser/remote/make-patches.py` into `browser/patches/`.
- `blocklist/blocklist.json`: the distraction list, shared by the browser and the demo.
- `demo/`: an interactive SvelteKit mock of Mast, used for design.
- `design/`: brand, canvas designs, README images. `design/assets/` holds third-party
  reference art and is gitignored: never commit it.
- Docs: `browser/docs/RELEASING.md` (releases), `UPSTREAM.md` (what Mast touches in
  Chromium), `ROADMAP.md`, `REBASE-LOG.md`.

## Rules

- **Builds cost money.** Never run `./mast build`, `shots`, `up` or `unattended` unless the
  maintainer says "build". `./mast check-patches` is free and local: run it after editing
  `make-patches.py`.
- **Commit straight on main.** No branches or pull requests unless asked.
- **Python through uv:** `uv run --no-project python …`, `uvx` for tools.
- **Don't clone Chromium, Brave or other large repos.** Fetch single files:
  `node browser/tools/base-file.mjs <path>` gives Chromium's file as Mast's build sees it.
- **Built-in pictures must be public domain or CC0**, credited in
  `browser/wallpapers/CREDITS.md`.
- **Ember (the accent colour) means blocked.** Don't use it for anything else in the UI.

## Releasing

Add what's new under "## Unreleased" in `CHANGELOG.md` and push. Then, only when the
maintainer asks for a release:

```
cd browser
MAST_SKIP_FETCH=1 ./mast build && ./mast shots && ./mast release; ./mast down --keep
```

`./mast release` hands the build to `.github/workflows/release.yml`, which signs and
publishes it. Details in `browser/docs/RELEASING.md`.
